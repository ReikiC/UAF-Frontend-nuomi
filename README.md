# Universal Agent Frontend - MVP 设计稿（超简版）

## 📋 项目概述

一个最简单的聊天界面，支持API切换。

---

## 🎯 功能需求（MVP）

1. **聊天界面** - 发送消息，显示回复
2. **API切换** - 3个按钮切换不同的API endpoint
3. **基础样式** - 简洁的UI

---

---

## 🔧 API 端点

| 按钮名称 | API 端点 | 说明 |
|---------|---------|------|
| 智能聊天 | `/api/v1/chat` | 带MCP工具的聊天 |
| 基础聊天 | `/api/v1/chat/basic` | 无工具的聊天 |
| 流式聊天 | `/api/v1/chat/stream` | 流式响应 |
| 流式聊天 | `/api/v1/chat/basic/stream` | 无工具的流式响应 |
